# 🎉 ديوانية الألعاب

ألعاب جماعية للديوانية والسهرات، كويتية ١٠٠٪ 🇰🇼. الشاشة الكبيرة على التلفزيون أو اللابتوب، وكل واحد يلعب من تلفونه.

| اللعبة | الفكرة | اللاعبين |
|---|---|---|
| 🎭 **كذبة الديوانية** | تطلع معلومة صج ناقصها كلمة. اكتب كذبة تمشي على الربع، وصوّت على الجواب الصج | من ٢ |
| 👀 **منو فينا؟** | "منو فينا ينام بالديوانية؟" صوّت على واحد من الربع، واللي يصوّت مع الأغلبية ياخذ نقاط | من ٢ |
| ⚡ **صج ولا چذب؟** | معلومة عن الكويت، صج ولا چذب؟ الأسرع ياخذ نقاط أكثر | من ١ |
| 🧩 **حزّر الإيموجي** | 🌙🍬👧 = ؟ اختار الجواب الصج من ٤ خيارات | من ١ |
| 🕵️ **مافيا الديوانية** | أدوار سرية (مافيا 😈، دكتور 🩺، شرطي 🕵️، مواطن 🙂). بالليل المافيا يقتلون، وبالنهار تتناقشون وتطردون منو تشكّون فيه | من ٤ (أحلى شي ٦ وفوق) |

آخر جولة في ألعاب النقاط نقاطها **دبل** 🔥

**عدد المافيا:** واحد إذا كنتوا ٤ إلى ٦ لاعبين، اثنين من ٧ إلى ٩، وثلاثة من ١٠ وفوق.

## التشغيل

تحتاج [Node.js](https://nodejs.org) بس، وما فيه أي مكتبات تنزّلها.

```bash
npm start
```

1. افتح الشاشة الكبيرة: `http://localhost:3000/host`
2. الربع يمسحون رمز QR أو يدخلون الرابط من تلفوناتهم (لازم يكونون على نفس الواي فاي)
3. اختاروا لعبة!

## إضافة محتوى

كل المحتوى في مجلد `content/`:

- `lie.js`: معلومات كذبة الديوانية (`q` المعلومة، `a` الجواب، `alt` طرق ثانية لكتابته، `lies` كذبات احتياطية)
- `who.js`: أسئلة منو فينا
- `tf.js`: معلومات صج ولا چذب (`s` المعلومة، `a` صج أو چذب، `note` توضيح)
- `emoji.js`: ألغاز الإيموجي (`e` الإيموجي، `a` الجواب، `o` الخيارات الغلط)

⚠️ تأكد إن كل معلومة صج ١٠٠٪ قبل لا تضيفها.

## النشر على الإنترنت

أسهل طريقة مجانية هي [Render](https://render.com): ارفع المجلد على GitHub، بعدين سوّ **New → Web Service**، وخل الـ Start command يكون `npm start`.
